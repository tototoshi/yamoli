Yamoli の使い方
  views: doc
  description: Yamoli は、行に YAML のような属性を持たせられるアウトラインエディタです。行を書き、インデントで入れ子にし、折りたたみとズームで整理します。属性を付けると、同じアウトラインがガントチャートや図、スライドになります。
  画面の言語はブラウザの言語に合わせて日本語か英語になり、**⋯** メニューで切り替えられます。右上の **?** でキーボードショートカットの一覧と、このガイドを開けます。
  このガイドもアウトラインで書かれていて、ドキュメントビューで表示しています。左の **アウトラインで開く** で自分のアウトラインに取り込めば、どう書かれているかを見たり、スライドにしたりできます。
  # 書く
    ## 行
      **Enter** で新しい行（カーソルの位置で分割）、**⌘Enter** でカーソルの位置によらず下に新しい行（子の行の後ろ）。**Tab / Shift+Tab** でインデント・アウトデント。● をクリックするとその項目にズームし、上部のパンくずで戻ります。
      書式（`**太字**`、`*斜体*`、`~~取り消し~~`、バッククォートで囲むコード、`[文字](https://…)`、色を付ける `[文字]{red}`）は入力中にそのまま表示され、記号は薄く出ます。
      文字を選んで **⌘B**（太字）・**⌘I**（斜体）・**⌘⇧X**（取り消し線）・**⌘E**（コード）で付け、もう一度で外せます。**⌘⇧H** で色の小窓が出て、1〜7 で色、0 で色を外します（macOS 以外は ⌘ の代わりに Ctrl）。図の箱のメニューの名前・説明、矢印のラベル（メニューでもダブルクリックでも）でも同じです。
      色は `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray` か `#hex` で、中に太字なども書けます（`[**重要**]{red}`）。図の箱の名前や説明、矢印のラベルにも効きます。
      リンクにカーソルを置くと行き先が吹き出しで出ます。**⌘K**（macOS 以外は Ctrl+K）でリンクを追加・編集でき、選択した文字に URL を貼り付けてもリンクになります。
      `[[` で他の項目へのリンクを入れます。`//` と打つと日付の候補（今日・明日・昨日・来週の月曜・カレンダー）が出て、選ぶと `2026-11-20` の形で入ります。`//12/24` や `//+3`（3 日後）のように続けて打つと、その日になります。**⌘P**（macOS 以外は Ctrl+P）で名前の一部から項目へジャンプします。
      よく開く項目は **⌘D**（または行のメニュー）でブックマークすると、上部の栞のボタンから開けます。⌘P でも先頭に出ます（もう一度 ⌘D で外す）。
      macOS では **Ctrl+K** でカーソルから行末まで削除し、**Ctrl+Y** で貼り戻せます。行の末尾での Ctrl+K は、Ctrl+D と同じく次の行を結合します。
    ## 選択・コピー・貼り付け
      行の端で **Shift+↑↓**、**Shift+クリック**、またはドラッグで複数の行を選べます。入力中に **Esc** を押すと、その行が選ばれた状態になります（もう一度 Esc で選択を外します。ドキュメントビューなどでは Esc で入力を抜けるだけです）。そのまま Tab / Shift+Tab、Backspace、⌘C / ⌘X、⌘Shift+Enter がまとめて効き、どれかの ● をドラッグすると一緒に動きます。
      行のメニュー（● を右クリック）の **ツリーをコピー** で、その項目を下の行ごとコピーします。折りたたんだ行や非表示の行も含みます。
      Yamoli でコピーした行は、貼り付けると元のまま入ります（属性・ブロック・複数行のテキスト・完了状態も）。ほかのアプリには Markdown のリストとして貼られます。
      複数行のテキストを貼り付けると行になります。Markdown のリストは入れ子を保ち（`- 名前: 値` は上の行の属性）、YAML は属性・入れ子・ブロックに、チェックリスト（`- [ ]` / `- [x]`）はタスクに、` ```ts ` などで囲んだコードはその言語のコードブロックになります（テキストビューの Markdown を貼り直すと、コードブロックも元の場所に戻ります）。
      Web ページなどからコピーした文章は、リンクを `[文字](https://…)` のリンクにして貼り付けます。段落や見出しはそれぞれ 1 行に、箇条書きは入れ子のまま行になります。
    ## タスク
      **タスク** は、メモではなく「やること」の行です。行の先頭に `[ ] ` と打つとタスクになり（`[x] ` なら完了済み）、名前の前にチェックボックスが出ます。チェックで完了（⌘Shift+Enter）、外すと再開です。行の先頭で Backspace を押すと普通の行に戻ります。**⌘L** や行のメニューでも切り替えられます。完了した行もタスクです。`duration`・`end`・`due` を持つ行は、チェックボックスは付きませんが、「タスクだけ」や検索ではタスクとして数えます。
      表示バーの **タスクだけ** でタスクだけを表示し、その上の行は薄く表示します。検索では `is:task` / `is:todo` で探せます。テキストビューではタスクを `- [ ]` / `- [x]` で書き出します。
    ## 属性とブロック
      行の先頭で `名前: ` と入力すると **属性** の行になります。値の先頭で Backspace を押すと普通の行に戻ります。
      値のない属性は下に行を持てます。下が属性ならオブジェクト、普通の行ならリストになります。
      **ブロック**（Alt+D）は複数行の値を持つ属性です。Markdown・CSV・コード・テキスト・画像・ファイルから選べ、YAML では `note: !markdown |` と書かれます。コードは形式の横に言語（`ts`、`python` …）を書けます。
      行に **画像やファイルを貼り付ける** か **ドロップする** と、その項目にブロックが付きます。画像は画像のブロック（`image: !image files/….png`、2行目以降は説明文）として表示され、それ以外のファイル（PDF など）はファイル名とサイズのリンク（`file: !file`）になり、クリックすると元の名前でダウンロードされます。
      画像やファイルはデータファイルの隣の `files/` フォルダに保存され、Markdown の中でも `![説明](files/….png)` や `[議事録](files/….pdf)` と書けます。ファイルに保存しているとき（`npm run dev` / `preview`）だけ使えます。
      属性の名前や値の入力中は、使ったことのある名前・値が下に出ます。**↓** で選び、**Enter** で決定します。
      表示バーの **属性** の設定で、属性の行をそのまま表示するか、各行の属性を1行の要約にまとめるか（クリックで開く）、隠すかを選べます。
    ## YAML として見ると
      属性を使い始めると、アウトラインの編集は YAML の編集とほぼ同じになります。アプリは属性を読んで動きを変えます。日付があればガントチャートを描き、`layout` があればスライドにします。
      アウトライン：
        例: !markdown |
          ```
          ・プロジェクト
            ・start: 2026-11-09
            ・要件定義
              ・duration: 3d
            ・設計
              ・duration: 2d
              ・after: 要件定義
          ```
      YAML ビュー：
        例: !markdown |
          ```yaml
          text: プロジェクト
          start: 2026-11-09
          children:
            - id: 1a2b3c4d5e6f
              text: 要件定義
              duration: 3d
            - text: 設計
              duration: 2d
              after: "[[1a2b3c4d5e6f]]"
          ```
      `after` があるので、設計は要件定義が終わった次の稼働日から始まる予定になります。
  # スケジュール
    ## 属性
      ガントチャートは、`views: gantt` を付けた項目で使えます（「ビュー」参照）。次の属性を読みます：
        表: !markdown |
          | 属性 | 例 | 意味 |
          | --- | --- | --- |
          | `views` | `gantt` | ガントチャートを有効にする（「ビュー」参照） |
          | `duration` | `3d` / `2w` / `10cd` / `0d` | 期間（稼働日 / 週 / 暦日）。`0d` はマイルストーン。ガントでは、下に行のない行は書かなくても 1 日 |
          | `start` | `2026-11-10` | この日より前には始めない。子にも継承される。どこにもなく、依存もなければ今日から |
          | `end` | `2026-11-14` | `duration` の代わりに終了日を書く。`start` からこの日までのバーになる（暦日なので土日も含む）。依存がもっと遅く終わると、バーごと後ろにずれる |
          | `after` | `[[要件定義]], [[API 設計]]` | 依存。すべて終わってから始まる。親の依存は子にも効く |
          | `due` | `2026-11-20` | 期限。過ぎて終わると遅延として表示 |
          | `completed` | `2026-11-09` | 完了した日（⌘Shift+Enter で自動で付き、再開すると消える） |
          | `workdays` | `mon-fri` | 稼働する曜日（既定は `mon-fri`）。子にも継承される |
          | `holidays` | `jp`, `2026-12-29..2027-01-03` | 休日。`jp` で日本の祝日を加える |
      子を持つ項目は、子の期間全体にまたがります。★ はクリティカルパス（遅れるとプロジェクト全体が遅れる作業）です。
    ## チャート
      ガントチャートには依存の矢印と期限の線が出ます。− / + で1日の幅を変えられ（長いプロジェクトなら年と月の目盛りまで縮小）、**全体** でスケジュール全体が入る幅になります。
      **日付** で、項目名の右に開始日・終了日・日数（稼働日）の列を出します。
      チャートの上のボタンで、項目名・日付・凡例ごと SVG・PNG ファイルとして保存したり、画像としてコピーしたりできます。
    ## チャートの上で編集
      ガントチャートの上でも日程を編集できます。変更は属性として書き込まれるので、アウトラインと同じものです。
      できる操作は次のとおりです：
        **バーをドラッグ**：開始日を動かします（`start` が付きます。`end` で書いた項目は `end` も一緒にずれます）。依存先より前には動かせず、依存先が終わった後の位置で止まります。
        **バーの右端をドラッグ**：終了日を動かします。`duration` を稼働日数で書き換えます（`10cd` のような暦日の項目は暦日のまま、`end` で書いた項目は `end` を書き換えます）。
        **名前・開始・終了・日数をクリック**：その場で入力できます。開始・終了ではカレンダーも開き、選んだ日がそのまま入ります。日付は `12/3` のように月/日でも書けます（今年として読みます）。日数を `0` にするとマイルストーンになります。日程のない項目に開始日や日数を入れれば、そこから日程が付きます。Enter で確定、Esc で取り消しです。
        **作業を足す**：チャートの上の **+ 作業** で、最後に行が足され、そのまま名前を入力できます（何も入れずに Esc で取りやめ）。足した行には今日から 1 日のバーがすぐ出るので（プロジェクトがもっと後に始まるなら、その日から）、ドラッグして動かしたり伸ばしたりします。
        **バーを描く**：`end` だけを書いた行など、バーのない行の上をドラッグすると、その日からその日までのバーになります（`start` と稼働日数の `duration` が付きます。クリックだけなら 1 日）。
        **依存を作る**：バーにカーソルを当てると、右に小さな丸が出ます。そこから、後に始めたい行までドラッグすると、その行の `after` に依存が足されます。循環してしまう依存や、親子の項目の間の依存は作れません。
        **依存を消す**：矢印をクリックして選び、Delete（または矢印に出る ×）で消します。その行の `after` から外れます。
        名前の右の **›** で、その項目にズームします。
      子の期間から決まる親の項目（まとめのバー）は、ここでは編集できません。ドラッグ中は Esc でバーを元に戻せます。
  # 図
    ## 書き方
      図ビューは、`views: diagram` を付けた項目で、ズームしている項目の行を図にします。たとえばシステム構成図を次のように書くと：
        例: !markdown |
          ```
          ・本番環境
            ・views: diagram
            ・ユーザー
              ・shape: actor
              ・to: [[Web]] HTTPS
            ・VPC
              ・shape: frame
              ・Private
                ・shape: frame
                ・Web
                  ・to: [[API]] gRPC
                ・API
                  ・to: [[DB]]
                ・DB
                  ・shape: db
          ```
      次のように描かれます：
        例: !markdown |
          ```
                ┌ VPC ─────────────────────────┐
                │ ┌ Private ─────────────────┐ │
          ☺ ──▶ │ │ Web ─gRPC─▶ API ──▶ (DB) │ │
                │ └──────────────────────────┘ │
                └──────────────────────────────┘
          ```
      書き方と描かれ方は次のとおりです：
        表: !markdown |
          | 書き方 | 描かれ方 |
          | --- | --- |
          | 行 | 箱。下の行は箱の中に `• …` で並ぶ |
          | `shape: frame` | 下の行を囲む枠。中の行はそれぞれ箱になる。枠線は `frame solid` / `frame none`（既定は点線） |
          | `shape: container` | 中に箱を並べる箱（入れ物）。枠と同じく下の行が箱になり、見た目は普通の箱 |
          | `shape: row` / `column` / `grid` | 中の箱を矢印に関係なく、アウトラインの順に並べる。`row` / `横`: 横一列、`column` / `縦`: 縦一列、`grid` / `格子`: 格子状に折り返す（`grid 3` で3列。省略するとほぼ正方形になる列数）。それだけだと枠も名前も描かない、見えない並びになる（行の名前はアウトライン上のメモ。矢印の線は、中の箱は避けるが、並びの空いた所は通る）。`row dashed` / `grid 3 solid` / `row none` / `frame row` のように枠線か `frame` を続けると、名前付きの枠になる。中の矢印は線を引くだけで、並びには使わない |
          | 属性の中の `[[リンク]]` | 矢印。リンクの後ろの言葉（なければ属性名、`to` を除く）がラベルになる。`after` の矢印は依存先から引かれる。同じ辺に付く矢印は、相手の位置の順に少しずつずらして付く |
          | `[[リンク]] SQL {red}` | その矢印だけの見た目。波かっこの中に色や `lines` と同じ言葉（`dashed`、`both` など）を書く。属性の名前で決まる見た目の上に重なる。ラベルの中の `[文字]{red}` はラベルの文字の色で、矢印の色ではない |
          | `[[リンク]] SQL @上` | 矢印の付く辺を決める。`@` の後ろがリンク先に入る辺、前がリンク元から出る辺（`下@上`、`右@`）。`上` / `下` / `左` / `右`（`top` / `bottom` / `left` / `right`）。決めた矢印は辺からまっすぐ出入りし、間に箱があれば直角に曲がってよける |
          | `shape` | `box` / `actor` / `db` / `queue` / `external` / `process`（楕円）/ `store`（データストア）/ `sticky` または `付箋`（注釈用の付箋。名前が折り返して書かれ、`to:` で箱につなぐと矢印なしの点線でその箱の隣に付く）。DFD なら、外部エンティティは `box`、プロセスは `process`、データストアは `store`、データフローは `to: [[箱]] 注文データ` のようなラベル付きの矢印で |
          | `color` | `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray` または `#hex` |
          | `font` / `文字色` | 箱や枠の文字の色。`color` と同じ色名か `#hex`。名前はその色、説明と属性は少し薄く描く。文字の一部だけの色は、文字の中に `[文字]{red}` と書く（⌘⇧H） |
          | `border` / `枠線` | 箱や枠の線。`solid`（実線）/ `dashed`（破線）/ `dotted`（点線）/ `none`（なし）、`thick`（太）/ `thin`（細）、`double`（二重）、`round`（丸）/ `square`（角）、`shadow`（影）、色を空白区切りで組み合わせる（例: `border: thick dashed red`、`枠線: 二重 影`） |
          | `icon` | 名前の前のアイコン: `server`, `database`, `storage`, `cloud`, `globe`, `user`, `users`, `mobile`, `desktop`, `browser`, `code`, `function`, `queue`, `bolt`, `lock`, `key`, `shield`, `mail`, `bell`, `chart`, `gear`, `container`, `file`, `search`, `cpu`、または絵文字。actor では人型の代わりになる |
          | `note` / `description` | 箱や枠の名前の下に出る説明文。折り返して表示し、長いと箱が横に、さらに縦に広がる。`note` のブロックでもよい。ズームした項目に書くと図全体の説明として、図の上に出る（SVG・PNG にも入る）。説明と箱の名前の中の `**太字**`・`*斜体*`・`~~取り消し~~`・コード・`[文字]{red}` はそのように描かれる |
          | その他の属性 | 箱の中の小さな `key: value` の行 |
          | `layout`（ズームした項目に） | 一番外の箱を `shape: row` などと同じ言葉で並べる。枠や入れ物に書くと `shape` の並べ方より優先 |
          | `direction`（ズームした項目に） | `LR`（左から右、既定）/ `TB`（上から下） |
    ## 線と書き出し
      線の見た目は、書いた属性の名前で決まります。`async:` は点線、`both:` は両矢印、`link:` は矢印なし、それ以外（`to:` など）は普通の矢印です。ズームした項目に `lines` 属性を置くと、名前ごとに決められます（`calls: dotted red`、`sync: both` のように、`solid` / `dashed` / `dotted`、`arrow` / `both` / `none`、色を書きます）。
      箱の中に並んだ行への矢印は、その箱に引かれます。箱を横切る線は迂回します。
      図の上のボタンで SVG・PNG ファイルとして保存したり、画像としてコピーして資料に貼ったりできます。箱を選んでいるときは「選択した箱だけ」で、選んだ箱（枠なら中身ごと）とその間の矢印だけを切り出せます。選択の印やハイライトは画像に入りません。
    ## 図の上で編集
      図の上でもそのまま編集できます。書き換わるのはアウトラインの行と属性なので、図とアウトラインはいつも一致します。
      できる操作は次のとおりです：
        **名前**：箱を選んでそのまま入力すると書き換わります（日本語入力も可）。ダブルクリックか Enter なら今の名前から直せます。矢印も、選んで入力するとラベルが書き換わります。
        **説明**：右クリックメニューの一番上に名前と説明の欄があり、そのまま書き換えられます（説明は Shift+Enter で改行）。メニューを閉じると書き込まれ、Esc なら取りやめます。矢印の右クリックメニューにはラベルの欄があります。説明は `note` 属性になり、複数行ならテキストのブロックになります。すでに `description` などがあればそこを書き換えます。
        **形・色・文字の色・線**：箱を右クリックしたメニューの「形・塗り・文字・線」のボタン（今の見た目が出ています）を押すと、その選択肢が開きます（`shape` / `color` / `font` / `border` 属性になります）。文字と線はメニューを開いたまま何度でも切り替えられます。同じメニューから、中や後ろに箱を追加したり（普通の箱の中に追加すると、その箱は入れ物になります）、アウトラインで開いたり、削除したりできます。
        **箱の追加**：図の左上の **+ 箱を追加**。名前はすぐ書けますが、書かずに Esc でも構いません。名前のない行は何も書いていない箱になり、形や色、アイコンだけの箱に使えます（名前を消すと、今ある箱もそうなります）。
        **拡大・縮小**：図の右上の **−** / **+** か、⌘（macOS 以外は Ctrl）を押しながらホイール（トラックパッドならピンチ）。％の表示を押すと原寸に、**全体** で図全体が画面に収まる大きさになります（開いたときもこの大きさで、原寸より大きくはなりません）。図の空いた所をドラッグするとスクロールします。書き出す画像はいつも原寸です。
        **矢印を引く**：箱にマウスを乗せると出る点から、つなぎたい箱までドラッグします（`to: [[箱]]` が付きます）。矢印をクリックして × か Delete で消せます。
        **矢印のラベルと見た目**：矢印をダブルクリック（選んで Enter）するとラベルを書き換えられます（リンクの横の言葉になります。依存の矢印にはラベルはありません）。矢印を右クリックすると線の種類（矢印・破線・両矢印・線のみ、`lines` で決めた名前）と色を選べます（色はリンクの横に `{red}` のように書かれます）。リンクを書いた属性の名前が `to` / `async` / `both` / `link` などに変わります（`after` の依存はそのまま）。
        **矢印の付け替え**：選んだ矢印の両端に出る点を同じ箱の別の辺へドラッグすると、その辺に付くよう固定できます（`@上` などが書かれます。矢印の右クリックで「付く位置を自動に戻す」）。別の箱へドラッグすると、つなぎ変えられます（先を変えるとリンク先が、元を変えるとリンクを書いた属性がその箱へ移ります。`after` の依存も同じで、循環する場合は変わりません）。
        **移動**：箱を別の枠へドラッグすると、その枠の中に移ります。普通の箱の真ん中に落とすと、その箱が入れ物（`shape: container`）になって中に入ります。端に落とすとその箱の前に並びます。入れ物が空になると普通の箱に戻ります。`row` などで並べた枠の中では、落とした位置で順番が入れ替わります。ドラッグ中に Esc で取りやめます。
        **削除**：選んだ箱は Delete で削除できます（⌘Z で戻せます）。
        **複数選択**：Shift（または ⌘）を押しながらクリックすると、箱を複数選べます。選んだ箱を右クリックすると「横に並べる・縦に並べる・格子に並べる・枠で囲む」で、最初の箱のあった場所に `shape: row` などの行を作ってまとめます（並べるだけのものは図に名前が出ません。枠は作ってすぐ名前を入力できます）。Delete・⌘C・⌘X もまとめて効きます。枠を右クリックして「囲みを外す」で、中の箱を元の場所に出して枠を消します。
        **コピーと貼り付け**：⌘C で選んだ箱を中の行ごとコピー（⌘X で切り取り）し、⌘V で選んだ箱のすぐ後ろ（何も選んでいなければ最後）に貼り付けます。一緒にコピーした箱どうしの矢印はコピーの間に付き、外への矢印はそのまま残ります。ほかから貼り付けた文章は 1 行 1 つの箱になります。マインドマップでも同じです。
  # スライド
    ## スライドを作る
      スライドは、`views: slides` を付けた項目で使えます。ズームした項目がデッキ、その下の各行が1枚のスライドです。スライドの下の行は箇条書き、ブロックは本文になります。
      左のスライド一覧には、各スライドが小さな絵で並びます（編集すると、その場で絵も変わります）。**+ スライド** で今のスライドの後に新しいスライドを足し（そのままタイトルを入力できます）、ドラッグで順番を入れ替え、マウスを乗せると出る × で削除できます（削除は通知から取り消せます）。
      スライドの下のメニューで、そのスライドのレイアウトを選べます（`layout:` が書かれ、標準に戻すと消えます）。レイアウトは次のとおりです：
        **標準**：タイトルの下に箇条書きとブロック。
        **中央**：タイトルと箇条書きを中央に。
        **2 段組**：箇条書きをブロックと左右に並べるか、箇条書きを半分ずつ左右に。
        **タイトルのみ**：デッキの表紙のように、タイトルとサブタイトルだけ。
        **区切り**：章の始まりのページ。タイトルを大きく左に。
        **カード**・**ステップ**・**数字**：1 段目の箇条書きを 1 つずつ、カード・番号付きの手順・大きな数字にして並べます。下の行はその中に出ます。
        **ひとこと**：1 つ目の箇条書きを中央に大きく出します。
      箇条書きやブロックがスライドに入りきらないときは、入るまで文字を小さくします（半分まで。それでも入らない分は切れます）。
    ## 画像
      サブタイトルや画像のないスライドには、スライドの下に **+ サブタイトル**・**+ 画像** が出ます。画像はスライドに貼り付けたりドロップしたりしても入ります（ファイルに保存しているときだけ）。
      画像は何枚でも置けます（2 枚目からは `image:` の下のリストになります）。画像にマウスを乗せると左上に出る × で外せます。アドレスを空にして Backspace を押しても外れます。
      画像にマウスを乗せると出るメニューで、置き場所を選べます（`image-at:` が書かれ、右に戻すと消えます）。置き場所は次のとおりです：
        **右**・**左**：箇条書きの横に、縦に並べて。
        **下**：箇条書きの下に、横に並べて。
        **大きく**：タイトルの下を画像だけで。3 枚までは横に、それより多いと格子状に並びます。
        **背景**：スライド全体に薄く敷きます（1 枚目）。メニューはスライドの右上に出て、**アドレス** で画像のアドレスを編集します。
    ## スライドの上で編集
      スライドのタイトル・箇条書き・サブタイトル・ブロック（表やコードなど）は、クリックするとその場で編集できます。画像はクリックすると下にアドレス（`image:` の値）の入力欄が出ます。
      ノートは **ノート** で開いた欄でそのまま書けます（ノートがなければ **ノートを書く** で `notes:` が付きます）。サブタイトルやノートは、空にして Backspace を押すと消えます（アウトラインと違い、先頭で Backspace を押しても普通の行には戻りません）。
      キー操作はアウトラインと同じで（Enter で次の行、Tab でインデント、↑↓ で前後の行）、別のスライドの行に移ると、そのスライドに切り替わります。タイトルで Enter を押すと最初の箇条書きになり、箇条書きで Shift+Tab を押すとそれが次のスライドになります。
      編集中にスライドをクリックすると編集が終わり、もう一度クリックするとページが進みます。
      スライドに埋め込んだ図やガントも、それぞれのビューと同じ操作で編集できます（マウスを乗せると右上に「+ 箱を追加」やガントの − / ＋ / 全体 が出ます）。図の箱やガントの矢印を選んでいる間は、矢印キーなどはページ送りでなく図の操作になります（Esc で選択を外すと戻ります）。
    ## 見せる
      ← → でページ送り、F で全画面、N でスピーカーノートを表示します。
      箇条書きが 2 つ以上あるスライドでは **1 つずつ** を押すと、→ のたびに箇条書きが 1 つずつ（下の階層ごと）出るようになります（`reveal: yes` が書かれます。デッキに `reveal: yes` を書くと全部のスライドがそうなり、スライドの `reveal: no` で外せます）。← で 1 つずつ戻り、前のスライドには全部出た状態で戻ります。編集しているあいだは全部出ます。
      **発表者ビュー** を押すと別のウィンドウが開き、今のスライド・次のスライド・ノート・経過時間（**リセット** で 0 に）・時刻が出ます。どちらのウィンドウで ← → を押してもページが進み、もう一方もついてきます。元のウィンドウを全画面にして見せ、発表者ビューを手元の画面に置いて使います。
      下の **PDF** ボタンで、すべてのスライドを1枚ずつ 16:9 のページにして印刷ダイアログを開きます。送信先で「PDF に保存」を選ぶと PDF になります（ノートは入りません）。
    ## 属性
      スライドは次の属性を読みます：
        表: !markdown |
          | 属性 | 付ける場所 | 意味 |
          | --- | --- | --- |
          | `subtitle` | デッキ、スライド | サブタイトル |
          | `theme` | デッキ | `dark` で暗いテーマ |
          | `layout` | スライド | `center` / `two-column` / `title` / `section` / `cards` / `steps` / `numbers` / `statement` |
          | `reveal` | デッキ、スライド | `yes` で箇条書きを 1 つずつ出す（スライドの `no` でデッキの `yes` を打ち消す） |
          | `notes` | スライド | スピーカーノート |
          | `image` | スライド | 画像（URL、または貼り付けた画像の `files/….png`）。何枚もなら下にリストで |
          | `image-at` | スライド | 画像の置き場所。`left` / `below` / `full` / `background`（`左` / `下` / `大きく` / `背景`）。なければ右 |
          | `embed` | スライド | `[[項目]]` のガントチャートを埋め込む（`[[項目]] diagram` で図、`[[項目]] mindmap` でマインドマップ）。リンクなしの `diagram` / `図` は、そのスライドの下の行を箇条書きでなく図にして描く（`mindmap` ならマインドマップ、`gantt` / `ガント` ならガントチャート） |
  # 検索
    検索（⌘F）は、書いた条件をすべて満たす行を探します。Esc で解除します。条件は次のとおりです：
      表: !markdown |
        | 条件 | 一致するもの |
        | --- | --- |
        | `word` / `"two words"` | 本文・属性名・値に含む |
        | `status:active` | 属性 `status` の値に `active` を含む |
        | `budget.amount:1200` | 入れ子の属性 |
        | `due:` | 属性 `due` を持つ |
        | `is:done` | 完了した行 |
        | `is:task` / `is:todo` | タスク / 未完了のタスク |
        | `is:bookmark` | ブックマークした項目 |
        | `is:ready` / `is:blocked` | 着手できる / 依存待ち |
        | `is:late` / `is:critical` / `is:milestone` | 遅延 / クリティカルパス上 / マイルストーン |
        | `is:cycle` | 依存が循環している |
        | `-条件` | 否定 |
    `is:` は日本語でも書けます（`is:完了`、`is:タスク`、`is:未完了`、`is:着手可`、`is:待ち`、`is:遅延` など）。大文字・小文字や全角・半角の違いは区別しません。
  # ビュー
    表示バーで切り替えます。項目ごとに、最後に使ったビューを覚えています（スライドは見せるためのものなので、項目を開いたときに勝手にスライドになることはありません）。
    アウトライン・テキスト・YAML・JSON はどの項目でも使えます。ガント・図・マインドマップ・スライド・ドキュメントは、そのために書いた行でないと意味をなさないので、項目ごとに有効にします。
    表示バーの **+** から選ぶと、その項目に `views` 属性が付き、項目とその下の行すべてで使えるようになります。`views: gantt, slides` のように直接書いても同じです（`gantt` / `diagram` / `mindmap` / `slides` / `doc`、または `ガント` / `図` / `マインドマップ` / `スライド`）。
    ビューは次のとおりです：
      **アウトライン**：すべての編集ができます。`views` を書いた項目は名前の前に「図」「ガント」などの印が付き、押すとそのビューで開きます。
      **ドキュメント**：行を箇条書きの文書として表示します（`#` で始まる行は見出し）。`views: doc` で有効になります（このガイドもドキュメントビューです）。
      **ガント**：スケジュールをチャートで表示します（「スケジュール」参照）。`views: gantt` で有効になります。
      **図**：行を箱と矢印で描きます（「図」参照）。`views: diagram` で有効になります。
      **マインドマップ**：ズームした項目から、その下の行を入れ子のとおりに枝分かれさせて描きます。`views: mindmap`（`マインドマップ`）で有効になります。
      **スライド**：行をスライドとして表示します（「スライド」参照）。`views: slides` で有効になります。
      **テキスト**：行を Markdown のリストで表示します。ほかへの貼り付け用です。リンクは項目名に、`#` の行は見出しに、段落の行は段落に、番号付きの行は `1. ` の番号付きリストに、引用は `> ` に、`---` は区切り線に、タスクはチェックリストに、Markdown のブロックはそのまま、コードのブロックは言語付きの ` ``` ` で囲まれて置いた場所に出て、「タスクだけ」「完了」「属性」の切り替えが効きます。
      **YAML / JSON**：ズームした項目をデータとして、色付き・読み取り専用で表示します。コピーボタン付きです。リンクされている項目には `id` が付きます。
    ## ドキュメント
      ドキュメントビューは、行をそのまま入れ子の箇条書きにして、上から読める文書として表示します。行の並び方から見出しや段落を推し量ることはしません。Markdown で書いたところは Markdown として描きます：
        `# ` で始まる行は見出しです（`## ` / `### ` でその下の段）。下の行は見出しの後ろに、その節として続きます。入力中は `#` が見え、ほかのときは隠れます（アウトラインでも同じ）。
        箇条書きの行の先頭で **Backspace** を押すと、その行が段落になります（ワープロと同じです。箇条書きの途中でも構いません）。段落の先頭で `- ` と打つと箇条書きに戻ります。段落で Enter を押すと次の行も段落です。段落の下の行は、段落の後ろに箇条書きで出ます。アウトラインでは、段落の行は白抜きの ● です。
        行に ` ``` ` と打って Enter（かスペース）を押すと、その行がその場でコードブロックになり、そのまま中を書けます。` ```ts ` のように続けて言語を書くと、その言語のコードになり、色が付きます（右上に言語名が出ます。Markdown ブロックの中の ` ```ts ` のコードも同じように色が付きます。マウスを乗せると右上に出る **コピー** で、中のコードをコピーできます。後からはブロックの右上の言語名（ドキュメントビュー。言語のないブロックはマウスを乗せると「言語」の欄が出ます）か、アウトラインでブロックの形式の横の欄で変えられ、YAML では `!code:ts` と書かれます）（⌘Enter で抜けて次の行へ、Esc で抜けるだけ。空にして Backspace で消えます）。
        長い文章や表は、Markdown のブロック（Alt+D）に書くこともできます。ブロックは置いた場所、行の間にそのまま出ます。
        行の先頭で `1. ` と打つと番号付きリストの項目に（番号は続く項目の順に自動で振られます）、`> ` と打つと引用になります。どちらも Enter で次の行も同じになり、行の先頭で Backspace を押すと段落に（アウトラインでは普通の行に）、`- ` と打つと普通の箇条書きになります。アウトラインでは、番号付きの行は ● の代わりに番号、引用は縦線で表示されます（`1. ` や `> ` を打って変わるのはドキュメントビューの中だけです）。
        `---` だけの行は区切り線になります（入力中は `---` が見えます）。
        空の行で `/` と打つと、その行を何にするかのメニューが出ます（見出し・箇条書き・番号付きリスト・タスク・段落・引用・区切り線・コードブロック・Markdown ブロック・日付）。続けて `/quo` や `/h2` のように打つと絞り込まれ、↑↓ と Enter かクリックで選びます。右に出ているのが、メニューなしで直接打つときの書き方です。`//` と 2 つ打てば今までどおり日付の候補です。
        `[ ]` で付けたタスクはチェックボックス付きです。
        右上の **文書をコピー** で、文書全体を書式付きでコピーします（見出し・リスト・コード・表などがそのまま、メールやほかの文書に貼れます。プレーンテキストしか受け付けない貼り先には Markdown で入ります）。属性と埋め込んだ図は入りません。
        `embed: [[項目]] diagram` を書いた場所にはその図（`mindmap` でマインドマップ、なしでガント）が入ります。ほかの属性は出ません。ズームした項目の `description` は冒頭のリード文になります。
      入力中の行は、**⌘⌥1** / **⌘⌥2** / **⌘⌥3** で見出しに（行の先頭に `#` が付きます）、**⌘⌥0** で普通の行に戻せます（macOS 以外は Ctrl+Alt。アウトラインでも使えます）。
      **⌘F** で文書内の検索が開きます（ほかのビューでは行を絞り込む検索です）。見つかったところに色が付き、Enter / Shift+Enter で次・前へ移ります。右の欄に置き換える言葉を入れて **置換**（その欄で Enter でも）で今の 1 か所を、**すべて置換** で文書中のすべてを置き換えます（まとめて ⌘Z 一回で戻せます）。大文字と小文字は区別しません。リンクのように、書いた文字と見える文字が違うところは置き換えません。Esc で閉じます。
      見出しが 3 つ以上ある文書は、左に目次が出ます（`##` の見出しまで）。クリックでその見出しへ移り、今読んでいる節に印が付きます。画面の幅が狭いときは出ません。
      文字はドラッグで行をまたいで選び、コピーできます。行やブロックをクリックすると（ドラッグでなく）、その場で編集できます。文字のないところ（行の右や左、行の間、最後の行より下）をクリックしても、その高さの行に入ります（文字の左なら行頭、それ以外は行末、一番下なら最後の行の末尾）。Enter で次の行、Tab / Shift+Tab でインデント、↑↓ で前後の行へと、キー操作はアウトラインと同じです。
      行にマウスを乗せると左に ⠿ のつまみが出ます。つまみをドラッグすると、その行を下の行ごと動かせます（アウトラインの ● のドラッグと同じで、行の上半分に落とすとその前、下半分なら後ろ、下に行がある行ならその最初に入ります。最後の行の後ろで左へずらすと、一段外に出ます）。ドラッグ中は Esc で取りやめ、動かした後は ⌘Z で戻せます。
      段落や見出しの先頭での Backspace は前の行に文章ごとつなげます（2 つの行が 1 つになります。箇条書きの行は、まず段落になります）。下に行のある行でもつながり、下の行は並びをそのままに 1 段上がります。中身のない行は「…」と薄く出るので、クリックして書くか Backspace で消せます。
      埋め込んだ図（`embed: diagram` / `mindmap`）やガントチャートも、それぞれのビューと同じ操作でその場で編集できます。図は右上の − / ＋ / 全体 や ⌘ + ホイールで拡大縮小でき、ガントは上の − / ＋ / 全体 / 今日 で日の幅を変えられます（どちらも開いた時点で全体が入る大きさ）。キー操作は図の中で選んだものにだけ効き、図の外をクリックすると選択が外れます。
    ## マインドマップ
      枠や矢印は使わず、すべての行がノードになります。行を選んで Tab で子を、Enter で次の行を追加し、そのまま名前を入力できます。
      矢印キーで枝をたどり、F2・Space・ダブルクリックで名前を変更、Delete で削除、ドラッグで別の行の下へ付け替えられます。
  # 保存
    アウトラインは入力するたびに自動で保存されます（上部のバーに状態が出ます）。別のタブやアプリの外でファイルが変わったときは、読み込み直すか自分の内容で上書きするかを選べます。
    ファイルに保存しているときは、その日最初の保存の前と、一度に 10 行以上を消した保存の前の内容が、データファイルの隣の `backups/` フォルダに残ります（日ごとのものは 30 日分、行を消す前のものは時刻付きで直近 20 個）。
    貼り付けた画像やファイルは `files/` フォルダにあり、一度保存したものは書き換えられません。
    ブラウザにもデータファイルごとに控えが残り、ファイルがなくなったときは、そのファイルの控えから作り直します（控えがなければサンプルから始まります。別のデータファイルの内容が使われることはありません）。
    **⋯** メニューから、読むためやほかのツールに渡すための **YAML**、元に戻せる **バックアップ（JSON）** として書き出せます（画像やファイルは含まれません）。ファイルに保存しているときは、アウトラインとそこで使っている画像・ファイルをまとめた **バックアップ（ZIP）** も書き出せ、**バックアップから読み込む** で JSON・ZIP どちらからも復元できます（ZIP の画像・ファイルは `files/` に戻ります）。
    **使われていないファイルを整理** は、アウトラインにも `backups/` のどのバックアップにも残っておらず、1週間以上前に追加された画像・ファイルを削除します。削除する数と大きさを確認してから実行します。
    使い方のスライドとサンプル（スケジュール付きのプロジェクト、システム構成図、DFD、マインドマップ）も、**⋯** メニューからいつでも追加し直せます。
