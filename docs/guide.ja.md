# Yamoli の使い方

Yamoli は、行に YAML のような属性を持たせられるアウトラインエディタです。行を書き、インデントで入れ子にし、折りたたみとズームで整理します。属性を付けると、同じアウトラインがガントチャートや図、スライドになります。

画面の言語はブラウザの言語に合わせて日本語か英語になり、**⋯** メニューで切り替えられます。右上の **?** でキーボードショートカットの一覧と、このガイドを開けます。

## 書く

### 行

- **Enter** で新しい行（カーソルの位置で分割）、**⌘Enter** でカーソルの位置によらず下に新しい行（子の行の後ろ）。**Tab / Shift+Tab** でインデント・アウトデント。● をクリックするとその項目にズームし、上部のパンくずで戻ります。
- 書式（`**太字**`、`*斜体*`、`~~取り消し~~`、`` `code` ``、`[文字](https://…)`、色を付ける `[文字]{red}`）は入力中にそのまま表示され、記号は薄く出ます。文字を選んで **⌘B**（太字）・**⌘I**（斜体）・**⌘⇧X**（取り消し線）・**⌘E**（コード）で付け、もう一度で外せます。**⌘⇧H** で色の小窓が出て、1〜7 で色、0 で色を外します（macOS 以外は ⌘ の代わりに Ctrl）。図の箱のメニューの名前・説明、矢印のラベル（メニューでもダブルクリックでも）でも同じです。色は `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray` か `#hex` で、中に太字なども書けます（`[**重要**]{red}`）。図の箱の名前や説明、矢印のラベルにも効きます。リンクにカーソルを置くと行き先が吹き出しで出ます。**⌘K**（macOS 以外は Ctrl+K）でリンクを追加・編集でき、選択した文字に URL を貼り付けてもリンクになります。
- `[[` で他の項目へのリンクを入れます。**⌘P**（macOS 以外は Ctrl+P）で名前の一部から項目へジャンプします。
- macOS では **Ctrl+K** でカーソルから行末まで削除し、**Ctrl+Y** で貼り戻せます。行の末尾での Ctrl+K は、Ctrl+D と同じく次の行を結合します。

### 選択・コピー・貼り付け

- 行の端で **Shift+↑↓**、**Shift+クリック**、またはドラッグで複数の行を選べます。そのまま Tab / Shift+Tab、Backspace、⌘C / ⌘X、⌘Shift+Enter がまとめて効き、どれかの ● をドラッグすると一緒に動きます。
- 行のメニュー（● を右クリック）の **ツリーをコピー** で、その項目を下の行ごとコピーします。折りたたんだ行や非表示の行も含みます。
- Yamoli でコピーした行は、貼り付けると元のまま入ります（属性・ブロック・複数行のテキスト・完了状態も）。ほかのアプリには Markdown のリストとして貼られます。
- 複数行のテキストを貼り付けると行になります。Markdown のリストは入れ子を保ち（`- 名前: 値` は上の行の属性）、YAML は属性・入れ子・ブロックに、チェックリスト（`- [ ]` / `- [x]`）はタスクになります。
- Web ページなどからコピーした文章は、リンクを `[文字](https://…)` のリンクにして貼り付けます。段落や見出しはそれぞれ 1 行に、箇条書きは入れ子のまま行になります。

### タスク

**タスク** は、メモではなく「やること」の行です。行の **タスク** ボタン（または **⌘L**）でタスクにすると、ボタンが完了（✓、⌘Shift+Enter）と再開（↺）に変わります。完了した行や、`duration`・`end`・`due` を持つ行もタスクとして数えます。

表示バーの **タスクだけ** でタスクだけを表示し、その上の行は薄く表示します。検索では `is:task` / `is:todo` で探せます。テキストビューではタスクを `- [ ]` / `- [x]` で書き出します。

### 属性とブロック

- 行の先頭で `名前: ` と入力すると **属性** の行になります。値の先頭で Backspace を押すと普通の行に戻ります。
- 値のない属性は下に行を持てます。下が属性ならオブジェクト、普通の行ならリストになります。
- **ブロック**（Alt+D）は複数行の値を持つ属性です。Markdown・CSV・コード・テキスト・画像・ファイルから選べ、YAML では `note: !markdown |` と書かれます。
- 行に **画像やファイルを貼り付ける** か **ドロップする** と、その項目にブロックが付きます。画像は画像のブロック（`image: !image files/….png`、2行目以降は説明文）として表示され、それ以外のファイル（PDF など）はファイル名とサイズのリンク（`file: !file`）になり、クリックすると元の名前でダウンロードされます。どちらもデータファイルの隣の `files/` フォルダに保存され、Markdown の中でも `![説明](files/….png)` や `[議事録](files/….pdf)` と書けます。ファイルに保存しているとき（`npm run dev` / `preview`）だけ使えます。
- 属性の名前や値の入力中は、使ったことのある名前・値が下に出ます。**↓** で選び、**Enter** で決定します。
- 表示バーの **属性** の設定で、属性の行をそのまま表示するか、各行の属性を1行の要約にまとめるか（クリックで開く）、隠すかを選べます。

### YAML として見ると

属性を使い始めると、アウトラインの編集は YAML の編集とほぼ同じになります。アプリは属性を読んで動きを変えます。日付があればガントチャートを描き、`layout` があればスライドにします。

アウトライン:

```
・プロジェクト
  ・start: 2026-11-09
  ・要件定義
    ・duration: 3d
  ・設計
    ・duration: 2d
    ・after: 要件定義
```

YAML ビュー:

```yaml
text: プロジェクト
start: 2026-11-09
children:
  - id: 1a2b3c4d5e6f
    text: 要件定義
    duration: 3d
  - text: 設計
    duration: 2d
    after: "[[1a2b3c4d5e6f]]"
```

`after` があるので、設計は要件定義が終わった次の稼働日から始まる予定になります。

## スケジュール

ガントチャートは、`views: gantt` を付けた項目で使えます（「ビュー」参照）。次の属性を読みます。

| 属性 | 例 | 意味 |
| --- | --- | --- |
| `views` | `gantt` | ガントチャートを有効にする（「ビュー」参照） |
| `duration` | `3d` / `2w` / `10cd` / `0d` | 期間（稼働日 / 週 / 暦日）。`0d` はマイルストーン |
| `start` | `2026-11-10` | この日より前には始めない。子にも継承される |
| `end` | `2026-11-14` | `duration` の代わりに終了日を書く。`start` からこの日までのバーになる（暦日なので土日も含む）。依存がもっと遅く終わると、バーごと後ろにずれる |
| `after` | `[[要件定義]], [[API 設計]]` | 依存。すべて終わってから始まる。親の依存は子にも効く |
| `due` | `2026-11-20` | 期限。過ぎて終わると遅延として表示 |
| `completed` | `2026-11-09` | 完了した日（⌘Shift+Enter で自動で付き、再開すると消える） |
| `workdays` | `mon-fri` | 稼働する曜日（既定は `mon-fri`）。子にも継承される |
| `holidays` | `jp`, `2026-12-29..2027-01-03` | 休日。`jp` で日本の祝日を加える |

子を持つ項目は、子の期間全体にまたがります。★ はクリティカルパス（遅れるとプロジェクト全体が遅れる作業）です。ガントチャートには依存の矢印と期限の線が出て、− / + で1日の幅を変えられ（長いプロジェクトなら年と月の目盛りまで縮小）、**全体** でスケジュール全体が入る幅になります。**日付** で、項目名の右に開始日・終了日・日数（稼働日）の列を出します。チャートの上のボタンで、項目名・日付・凡例ごと SVG・PNG ファイルとして保存したり、画像としてコピーしたりできます。

ガントチャートの上でも日程を編集できます。変更は属性として書き込まれるので、アウトラインと同じものです。

- **バーをドラッグ**: 開始日を動かします（`start` が付きます。`end` で書いた項目は `end` も一緒にずれます）。依存先より前には動かせず、依存先が終わった後の位置で止まります。
- **バーの右端をドラッグ**: 終了日を動かします。`duration` を稼働日数で書き換えます（`10cd` のような暦日の項目は暦日のまま、`end` で書いた項目は `end` を書き換えます）。
- **名前・開始・終了・日数をクリック**: その場で入力できます。日付は `12/3` のように月/日でも書けます（今年として読みます）。日数を `0` にするとマイルストーンになります。日程のない項目に開始日や日数を入れれば、そこから日程が付きます。Enter で確定、Esc で取り消しです。
- **依存を作る**: バーにカーソルを当てると、右に小さな丸が出ます。そこから、後に始めたい行までドラッグすると、その行の `after` に依存が足されます。循環してしまう依存や、親子の項目の間の依存は作れません。
- **依存を消す**: 矢印をクリックして選び、Delete（または矢印に出る ×）で消します。その行の `after` から外れます。
- 名前の右の **›** で、その項目にズームします。

子の期間から決まる親の項目（まとめのバー）は、ここでは編集できません。ドラッグ中は Esc でバーを元に戻せます。

## 図

図ビューは、`views: diagram` を付けた項目で、ズームしている項目の行を図にします。たとえばシステム構成図:

```
・本番環境
  ・views: diagram
  ・ユーザー
    ・shape: actor
    ・to: [[Web]] HTTPS
  ・VPC
    ・shape: frame
    ・Private
      ・shape: frame
      ・Web
        ・to: [[API]] gRPC
      ・API
        ・to: [[DB]]
      ・DB
        ・shape: db
```

と書くと、次のように描かれます:

```
      ┌ VPC ─────────────────────────┐
      │ ┌ Private ─────────────────┐ │
☺ ──▶ │ │ Web ─gRPC─▶ API ──▶ (DB) │ │
      │ └──────────────────────────┘ │
      └──────────────────────────────┘
```

| 書き方 | 描かれ方 |
| --- | --- |
| 行 | 箱。下の行は箱の中に `• …` で並ぶ |
| `shape: frame` | 下の行を囲む枠。中の行はそれぞれ箱になる。枠線は `frame solid` / `frame none`（既定は点線） |
| `shape: container` | 中に箱を並べる箱（入れ物）。枠と同じく下の行が箱になり、見た目は普通の箱 |
| `shape: row` / `column` / `grid` | 中の箱を矢印に関係なく、アウトラインの順に並べる。`row` / `横`: 横一列、`column` / `縦`: 縦一列、`grid` / `格子`: 格子状に折り返す（`grid 3` で3列。省略するとほぼ正方形になる列数）。それだけだと枠も名前も描かない、見えない並びになる（行の名前はアウトライン上のメモ）。`row dashed` / `grid 3 solid` / `row none` / `frame row` のように枠線か `frame` を続けると、名前付きの枠になる。中の矢印は線を引くだけで、並びには使わない |
| 属性の中の `[[リンク]]` | 矢印。リンクの後ろの言葉（なければ属性名、`to` を除く）がラベルになる。`after` の矢印は依存先から引かれる。同じ辺に付く矢印は、相手の位置の順に少しずつずらして付く |
| `[[リンク]] SQL {red}` | その矢印だけの見た目。波かっこの中に色や `lines` と同じ言葉（`dashed`、`both` など）を書く。属性の名前で決まる見た目の上に重なる。ラベルの中の `[文字]{red}` はラベルの文字の色で、矢印の色ではない |
| `[[リンク]] SQL @上` | 矢印の付く辺を決める。`@` の後ろがリンク先に入る辺、前がリンク元から出る辺（`下@上`、`右@`）。`上` / `下` / `左` / `右`（`top` / `bottom` / `left` / `right`）。決めた矢印は辺からまっすぐ出入りし、間に箱があれば直角に曲がってよける |
| `shape` | `box` / `actor` / `db` / `queue` / `external` / `process`（楕円）/ `store`（データストア）/ `sticky` または `付箋`（注釈用の付箋。名前が折り返して書かれ、`to:` で箱につなぐと矢印なしの点線でその箱の隣に付く）。DFD なら、外部エンティティは `box`、プロセスは `process`、データストアは `store`、データフローは `to: [[箱]] 注文データ` のようなラベル付きの矢印で |
| `color` | `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray` または `#hex` |
| `font` / `文字色` | 箱や枠の文字の色。`color` と同じ色名か `#hex`。名前はその色、説明と属性は少し薄く描く。文字の一部だけの色は、文字の中に `[文字]{red}` と書く（⌘⇧H） |
| `border` / `枠線` | 箱や枠の線。`solid`（実線）/ `dashed`（破線）/ `dotted`（点線）/ `none`（なし）、`thick`（太）/ `thin`（細）、`double`（二重）、`round`（丸）/ `square`（角）、`shadow`（影）、色を空白区切りで組み合わせる（例: `border: thick dashed red`、`枠線: 二重 影`） |
| `icon` | 名前の前のアイコン: `server`, `database`, `storage`, `cloud`, `globe`, `user`, `users`, `mobile`, `desktop`, `browser`, `code`, `function`, `queue`, `bolt`, `lock`, `key`, `shield`, `mail`, `bell`, `chart`, `gear`, `container`, `file`, `search`, `cpu`、または絵文字。actor では人型の代わりになる |
| `note` / `description` | 箱や枠の名前の下に出る説明文。折り返して表示し、長いと箱が横に、さらに縦に広がる。`note` のブロックでもよい。ズームした項目に書くと図全体の説明として、図の上に出る（SVG・PNG にも入る）。説明と箱の名前の中の `**太字**`・`*斜体*`・`~~取り消し~~`・`` `コード` ``・`[文字]{red}` はそのように描かれる |
| その他の属性 | 箱の中の小さな `key: value` の行 |
| `layout`（ズームした項目に） | 一番外の箱を `shape: row` などと同じ言葉で並べる。枠や入れ物に書くと `shape` の並べ方より優先 |
| `direction`（ズームした項目に） | `LR`（左から右、既定）/ `TB`（上から下） |

線の見た目は、書いた属性の名前で決まります。`async:` は点線、`both:` は両矢印、`link:` は矢印なし、それ以外（`to:` など）は普通の矢印です。ズームした項目に `lines` 属性を置くと、名前ごとに決められます: `calls: dotted red`、`sync: both`（`solid` / `dashed` / `dotted`、`arrow` / `both` / `none`、色）。

箱の中に並んだ行への矢印は、その箱に引かれます。箱を横切る線は迂回します。図の上のボタンで SVG・PNG ファイルとして保存したり、画像としてコピーして資料に貼ったりできます。箱を選んでいるときは「選択した箱だけ」で、選んだ箱（枠なら中身ごと）とその間の矢印だけを切り出せます。選択の印やハイライトは画像に入りません。

図の上でもそのまま編集できます。書き換わるのはアウトラインの行と属性なので、図とアウトラインはいつも一致します。

- **名前**: 箱を選んでそのまま入力すると書き換わります（日本語入力も可）。ダブルクリックか Enter なら今の名前から直せます。矢印も、選んで入力するとラベルが書き換わります。
- **説明**: 右クリックメニューの一番上に名前と説明の欄があり、そのまま書き換えられます（説明は Shift+Enter で改行）。メニューを閉じると書き込まれ、Esc なら取りやめます。矢印の右クリックメニューにはラベルの欄があります。説明は `note` 属性になり、複数行ならテキストのブロックになります。すでに `description` などがあればそこを書き換えます。
- **形・色・文字の色・線**: 箱を右クリックしたメニューの「形・塗り・文字・線」のボタン（今の見た目が出ています）を押すと、その選択肢が開きます（`shape` / `color` / `font` / `border` 属性になります）。文字と線はメニューを開いたまま何度でも切り替えられます。同じメニューから、中や後ろに箱を追加したり（普通の箱の中に追加すると、その箱は入れ物になります）、アウトラインで開いたり、削除したりできます。
- **箱の追加**: 図の左上の **+ 箱を追加**。
- **拡大・縮小**: 図の右上の **−** / **+** か、⌘（macOS 以外は Ctrl）を押しながらホイール（トラックパッドならピンチ）。％の表示を押すと原寸に、**全体** で図全体が画面に収まる大きさになります（開いたときもこの大きさで、原寸より大きくはなりません）。図の空いた所をドラッグするとスクロールします。書き出す画像はいつも原寸です。
- **矢印**: 箱にマウスを乗せると出る点から、つなぎたい箱までドラッグします（`to: [[箱]]` が付きます）。矢印をクリックして × か Delete で消せます。矢印をダブルクリック（選んで Enter）するとラベルを書き換えられます（リンクの横の言葉になります。依存の矢印にはラベルはありません）。矢印を右クリックすると線の種類（矢印・破線・両矢印・線のみ、`lines` で決めた名前）と色を選べます（色はリンクの横に `{red}` のように書かれます）。リンクを書いた属性の名前が `to` / `async` / `both` / `link` などに変わります（`after` の依存はそのまま）。選んだ矢印の両端に出る点を同じ箱の別の辺へドラッグすると、その辺に付くよう固定できます（`@上` などが書かれます。矢印の右クリックで「付く位置を自動に戻す」）。別の箱へドラッグすると、つなぎ変えられます（先を変えるとリンク先が、元を変えるとリンクを書いた属性がその箱へ移ります。`after` の依存も同じで、循環する場合は変わりません）。
- **移動**: 箱を別の枠へドラッグすると、その枠の中に移ります。普通の箱の真ん中に落とすと、その箱が入れ物（`shape: container`）になって中に入ります。端に落とすとその箱の前に並びます。入れ物が空になると普通の箱に戻ります。`row` などで並べた枠の中では、落とした位置で順番が入れ替わります。ドラッグ中に Esc で取りやめます。
- 選んだ箱は Delete で削除できます（⌘Z で戻せます）。
- Shift（または ⌘）を押しながらクリックすると、箱を複数選べます。選んだ箱を右クリックすると「横に並べる・縦に並べる・格子に並べる・枠で囲む」で、最初の箱のあった場所に `shape: row` などの行を作ってまとめます（並べるだけのものは図に名前が出ません。枠は作ってすぐ名前を入力できます）。Delete・⌘C・⌘X もまとめて効きます。枠を右クリックして「囲みを外す」で、中の箱を元の場所に出して枠を消します。
- ⌘C で選んだ箱を中の行ごとコピー（⌘X で切り取り）し、⌘V で選んだ箱のすぐ後ろ（何も選んでいなければ最後）に貼り付けます。一緒にコピーした箱どうしの矢印はコピーの間に付き、外への矢印はそのまま残ります。ほかから貼り付けた文章は 1 行 1 つの箱になります。マインドマップでも同じです。

## スライド

`views: slides` を付けた項目で使えます。ズームした項目がデッキ、その下の各行が1枚のスライドです。スライドの下の行は箇条書き、ブロックは本文になります。← → でページ送り、F で全画面、N でスピーカーノートを表示します。下の **PDF** ボタンで、すべてのスライドを1枚ずつ 16:9 のページにして印刷ダイアログを開きます。送信先で「PDF に保存」を選ぶと PDF になります（ノートは入りません）。箇条書きが 2 つ以上あるスライドでは **1 つずつ** を押すと、→ のたびに箇条書きが 1 つずつ（下の階層ごと）出るようになります（`reveal: yes` が書かれます。デッキに `reveal: yes` を書くと全部のスライドがそうなり、スライドの `reveal: no` で外せます）。← で 1 つずつ戻り、前のスライドには全部出た状態で戻ります。編集しているあいだは全部出ます。**発表者ビュー** を押すと別のウィンドウが開き、今のスライド・次のスライド・ノート・経過時間（**リセット** で 0 に）・時刻が出ます。どちらのウィンドウで ← → を押してもページが進み、もう一方もついてきます。元のウィンドウを全画面にして見せ、発表者ビューを手元の画面に置いて使います。サブタイトルや画像のないスライドには、スライドの下に **+ サブタイトル**・**+ 画像** が出ます。画像はスライドに貼り付けたりドロップしたりしても入り（ファイルに保存しているときだけ）、アドレスを空にして Backspace を押すと外れます。画像は何枚でも置けます（2 枚目からは `image:` の下のリストになります）。画像にマウスを乗せると左上に出る × で外せます。置き場所が右・左なら縦に、下なら横に並び、大きくなら 3 枚までは横に、それより多いと格子状に並びます（背景には 1 枚目）。画像にマウスを乗せると出るメニューで、置き場所を **右**（箇条書きの右）・**左**・**下**（箇条書きの下）・**大きく**（タイトルの下を画像だけで）・**背景**（スライド全体に薄く敷く。メニューはスライドの右上に出て、**アドレス** で画像のアドレスを編集）から選べます（`image-at:` が書かれ、右に戻すと消えます）。スライドの下のメニューで、そのスライドのレイアウト（標準・中央・2 段組・タイトルのみ）を選べます（`layout:` が書かれ、標準に戻すと消えます）。左のスライド一覧には、各スライドが小さな絵で並びます（編集すると、その場で絵も変わります）。一覧では、**+ スライド** で今のスライドの後に新しいスライドを足し（そのままタイトルを入力できます）、ドラッグで順番を入れ替え、マウスを乗せると出る × で削除できます（削除は通知から取り消せます）。箇条書きやブロックがスライドに入りきらないときは、入るまで文字を小さくします（半分まで。それでも入らない分は切れます）。

スライドのタイトル・箇条書き・サブタイトル・ブロック（表やコードなど）は、クリックするとその場で編集できます。画像はクリックすると下にアドレス（`image:` の値）の入力欄が出て、ノートは **ノート** で開いた欄でそのまま書けます（ノートがなければ **ノートを書く** で `notes:` が付きます）。サブタイトルやノートは、空にして Backspace を押すと消えます（アウトラインと違い、先頭で Backspace を押しても普通の行には戻りません）。キー操作はアウトラインと同じで（Enter で次の行、Tab でインデント、↑↓ で前後の行）、別のスライドの行に移ると、そのスライドに切り替わります（タイトルで Enter を押すと最初の箇条書きになり、箇条書きで Shift+Tab を押すとそれが次のスライドになります）。編集中にスライドをクリックすると編集が終わり、もう一度クリックするとページが進みます。スライドに埋め込んだ図やガントも、それぞれのビューと同じ操作で編集できます（マウスを乗せると右上に「+ 箱を追加」やガントの − / ＋ / 全体 が出ます）。図の箱やガントの矢印を選んでいる間は、矢印キーなどはページ送りでなく図の操作になります（Esc で選択を外すと戻ります）。

| 属性 | 付ける場所 | 意味 |
| --- | --- | --- |
| `subtitle` | デッキ、スライド | サブタイトル |
| `theme` | デッキ | `dark` で暗いテーマ |
| `layout` | スライド | `center` / `two-column` / `title` |
| `notes` | スライド | スピーカーノート |
| `image` | スライド | 画像（URL、または貼り付けた画像の `files/….png`） |
| `embed` | スライド | `[[項目]]` のガントチャートを埋め込む（`[[項目]] diagram` で図、`[[項目]] mindmap` でマインドマップ）。リンクなしの `diagram` / `図` は、そのスライドの下の行を箇条書きでなく図にして描く（`mindmap` ならマインドマップ、`gantt` / `ガント` ならガントチャート） |

## 検索

検索（⌘F）は、書いた条件をすべて満たす行を探します。Esc で解除します。

| 条件 | 一致するもの |
| --- | --- |
| `word` / `"two words"` | 本文・属性名・値に含む |
| `status:active` | 属性 `status` の値に `active` を含む |
| `budget.amount:1200` | 入れ子の属性 |
| `due:` | 属性 `due` を持つ |
| `is:done` | 完了した行 |
| `is:task` / `is:todo` | タスク / 未完了のタスク |
| `is:ready` / `is:blocked` | 着手できる / 依存待ち |
| `is:late` / `is:critical` / `is:milestone` | 遅延 / クリティカルパス上 / マイルストーン |
| `is:cycle` | 依存が循環している |
| `-条件` | 否定 |

`is:` は日本語でも書けます（`is:完了`、`is:タスク`、`is:未完了`、`is:着手可`、`is:待ち`、`is:遅延` など）。大文字・小文字や全角・半角の違いは区別しません。

## ビュー

表示バーで切り替えます。項目ごとに、最後に使ったビューを覚えています（スライドは見せるためのものなので、項目を開いたときに勝手にスライドになることはありません）。

アウトライン・テキスト・YAML・JSON はどの項目でも使えます。ガント・図・マインドマップ・スライドは、そのために書いた行でないと意味をなさないので、項目ごとに有効にします。表示バーの **+** から選ぶと、その項目に `views` 属性が付き、項目とその下の行すべてで使えるようになります。`views: gantt, slides` のように直接書いても同じです（`gantt` / `diagram` / `mindmap` / `slides`、または `ガント` / `図` / `マインドマップ` / `スライド`）。

- **アウトライン**: すべての編集ができます。`views` を書いた項目は名前の前に「図」「ガント」などの印が付き、押すとそのビューで開きます。
- **ドキュメント**: 行を見出しと文章にして、上から読める文書として表示します。`views: doc` で有効になります。
  - 下に行（またはブロックや `embed`）がある行は見出し（3 段まで。それより深いと段落）。ただし `。` や `：` で終わる行は段落になり、下の行はその下に続きます。`。` で終わる行の下の行（または下の行のどれかが文のとき）は、字下げせずその後ろに段落として並び、`：` で終わる行の下や語句ばかりのときは箇条書きになります。1 行が 1 段落で、1 つの段落にしたい文は 1 行に続けて書きます。
  - 下に何もない行は、並んだ行のどれも `。` などで終わらなければ箇条書き、1 つでも終わる文があれば 1 行ずつ段落。タスクはチェックボックス付きです。
  - 決め方が違うときは、行のまとまりにマウスを乗せて出る「箇条書き / 段落」で切り替えます（上の行に `doc: list` / `doc: text` が付きます。「自動」で戻せます）。
  - どの行を見出しにするかも選べます。行にマウスを乗せると左の余白に **H**（見出しにする）か **¶**（本文にする）が出ます（その行に `doc: heading` / `doc: body` が付き、もう一度押すと元に戻ります）。
  - ブロックはその場所に表示され、`embed: [[項目]] diagram` を書いた場所にはその図（`mindmap` でマインドマップ、なしでガント）が入ります。ほかの属性は出ません。ズームした項目の `description` は冒頭のリード文になります。
  - 行やブロックをクリックすると、その場で編集できます。Enter で次の行、Tab / Shift+Tab でインデント、↑↓ で前後の行へと、キー操作はアウトラインと同じです。書き換えると見出し・段落・箇条書きはすぐ描き直されます（下に行ができた行は見出しになる、など）。Enter は新しい段落（新しい行）、段落の先頭での Backspace は前の段落に文章ごとつなげます（2 つの行が 1 つになります）。中身のない行は「…」と薄く出るので、クリックして書くか Backspace で消せます。
  - 埋め込んだ図（`embed: diagram` / `mindmap`）やガントチャートも、それぞれのビューと同じ操作でその場で編集できます（図は箱を選んで名前を変える、ドラッグ、矢印を引く、Delete で消す、上の「+ 箱を追加」、右上の − / ＋ / 全体 や ⌘ + ホイールで拡大縮小、開いた時点で全体が見える大きさ。ガントは上の − / ＋ / 全体 / 今日 で日の幅を変えられ（開いた時点で全体が入る幅。ガントビューの幅とは別）、名前や日付のセルをクリックして入力、バーのドラッグ、バーの後ろの丸から依存関係を引くなど）。キー操作は図の中で選んだものにだけ効き、図の外をクリックすると選択が外れます。
- **ガント**: スケジュールをチャートで表示します（「スケジュール」参照）。`views: gantt` で有効になります。
- **図**: 行を箱と矢印で描きます（「図」参照）。`views: diagram` で有効になります。
- **マインドマップ**: ズームした項目から、その下の行を入れ子のとおりに枝分かれさせて描きます。枠や矢印は使わず、すべての行がノードになります。`views: mindmap`（`マインドマップ`）で有効になります。行を選んで Tab で子を、Enter で次の行を追加し、そのまま名前を入力できます。矢印キーで枝をたどり、F2・Space・ダブルクリックで名前を変更、Delete で削除、ドラッグで別の行の下へ付け替えられます。
- **スライド**: 行をスライドとして表示します（「スライド」参照）。`views: slides` で有効になります。
- **テキスト**: 行を Markdown のリストで表示します。ほかへの貼り付け用です。リンクは項目名に、タスクはチェックリストになり、「タスクだけ」「完了」「属性」の切り替えが効きます。
- **YAML / JSON**: ズームした項目をデータとして、色付き・読み取り専用で表示します。コピーボタン付きです。リンクされている項目には `id` が付きます。

## 保存

アウトラインは入力するたびに自動で保存されます（上部のバーに状態が出ます）。別のタブやアプリの外でファイルが変わったときは、読み込み直すか自分の内容で上書きするかを選べます。

ファイルに保存しているときは、その日最初の保存の前と、一度に 10 行以上を消した保存の前の内容が、データファイルの隣の `backups/` フォルダに残ります（日ごとのものは 30 日分、行を消す前のものは時刻付きで直近 20 個）。貼り付けた画像やファイルは `files/` フォルダにあり、一度保存したものは書き換えられません。ブラウザにもデータファイルごとに控えが残り、ファイルがなくなったときは、そのファイルの控えから作り直します（控えがなければサンプルから始まります。別のデータファイルの内容が使われることはありません）。

**⋯** メニューから、読むためやほかのツールに渡すための **YAML**、元に戻せる **バックアップ（JSON）** として書き出せます（画像やファイルは含まれません）。ファイルに保存しているときは、アウトラインとそこで使っている画像・ファイルをまとめた **バックアップ（ZIP）** も書き出せ、**バックアップから読み込む** で JSON・ZIP どちらからも復元できます（ZIP の画像・ファイルは `files/` に戻ります）。

**使われていないファイルを整理** は、アウトラインにも `backups/` のどのバックアップにも残っておらず、1週間以上前に追加された画像・ファイルを削除します。削除する数と大きさを確認してから実行します。使い方のスライドとサンプル（スケジュール付きのプロジェクト、システム構成図、DFD、マインドマップ）も、ここからいつでも追加し直せます。
