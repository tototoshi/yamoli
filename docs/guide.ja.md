# Yamoli の使い方

Yamoli は、行に YAML のような属性を持たせられるアウトラインエディタです。行を書き、インデントで入れ子にし、折りたたみとズームで整理します。属性を付けると、同じアウトラインがガントチャートや図、スライドになります。

画面の言語はブラウザの言語に合わせて日本語か英語になり、**⋯** メニューで切り替えられます。右上の **?** でキーボードショートカットの一覧と、このガイドを開けます。

## 書く

### 行

- **Enter** で新しい行（カーソルの位置で分割）、**⌘Enter** でカーソルの位置によらず下に新しい行（子の行の後ろ）。**Tab / Shift+Tab** でインデント・アウトデント。● をクリックするとその項目にズームし、上部のパンくずで戻ります。
- 書式（`**太字**`、`` `code` ``、`[文字](https://…)`）は入力中にそのまま表示され、記号は薄く出ます。リンクにカーソルを置くと行き先が吹き出しで出ます。**⌘K**（macOS 以外は Ctrl+K）でリンクを追加・編集でき、選択した文字に URL を貼り付けてもリンクになります。
- `[[` で他の項目へのリンクを入れます。**⌘P**（macOS 以外は Ctrl+P）で名前の一部から項目へジャンプします。
- macOS では **Ctrl+K** でカーソルから行末まで削除し、**Ctrl+Y** で貼り戻せます。行の末尾での Ctrl+K は、Ctrl+D と同じく次の行を結合します。

### 選択・コピー・貼り付け

- 行の端で **Shift+↑↓**、**Shift+クリック**、またはドラッグで複数の行を選べます。そのまま Tab / Shift+Tab、Backspace、⌘C / ⌘X、⌘Shift+Enter がまとめて効き、どれかの ● をドラッグすると一緒に動きます。
- 行のメニュー（● を右クリック）の **ツリーをコピー** で、その項目を下の行ごとコピーします。折りたたんだ行や非表示の行も含みます。
- Yamoli でコピーした行は、貼り付けると元のまま入ります（属性・ブロック・複数行のテキスト・完了状態も）。ほかのアプリには Markdown のリストとして貼られます。
- 複数行のテキストを貼り付けると行になります。Markdown のリストは入れ子を保ち（`- 名前: 値` は上の行の属性）、YAML は属性・入れ子・ブロックに、チェックリスト（`- [ ]` / `- [x]`）はタスクになります。

### タスク

**タスク** は、メモではなく「やること」の行です。行の **タスク** ボタン（または **⌘L**）でタスクにすると、ボタンが完了（✓、⌘Shift+Enter）と再開（↺）に変わります。完了した行や、`duration`・`end`・`due` を持つ行もタスクとして数えます。

表示バーの **タスクだけ** でタスクだけを表示し、その上の行は薄く表示します。検索では `is:task` / `is:todo` で探せます。テキストビューではタスクを `- [ ]` / `- [x]` で書き出します。

### 属性とブロック

- 行の先頭で `名前: ` と入力すると **属性** の行になります。値の先頭で Backspace を押すと普通の行に戻ります。
- 値のない属性は下に行を持てます。下が属性ならオブジェクト、普通の行ならリストになります。
- **ブロック**（Alt+D）は複数行の値を持つ属性です。Markdown・CSV・コード・テキスト・画像・ファイルから選べ、YAML では `note: !markdown |` と書かれます。
- 行に **画像やファイルを貼り付ける** か **ドロップする** と、その項目にブロックが付きます。画像は画像のブロック（`image: !image files/….png`、2行目以降は説明文）として表示され、それ以外のファイル（PDF など）はファイル名とサイズのリンク（`file: !file`）になり、クリックすると元の名前でダウンロードされます。どちらもデータファイルの隣の `files/` フォルダに保存され、Markdown の中でも `![説明](files/….png)` や `[議事録](files/….pdf)` と書けます。ファイルに保存しているとき（`npm run dev` / `preview`）だけ使えます。
- 属性の名前や値の入力中は、使ったことのある名前・値が下に出ます。**↓** で選び、**Enter** で決定します。
- 表示バーの **属性** の設定で、属性の行をそのまま表示するか、各行の属性を1行の要約にまとめるか（クリックで開く）、隠すかを選べます。

### YAML として見ると

属性を使い始めると、アウトラインの編集は YAML の編集とほぼ同じになります。アプリは属性を読んで動きを変えます。日付があればガントチャートを描き、`layout` があればスライドにします。

アウトライン:

```
・プロジェクト
  ・start: 2026-11-09
  ・要件定義
    ・duration: 3d
  ・設計
    ・duration: 2d
    ・after: 要件定義
```

YAML ビュー:

```yaml
text: プロジェクト
start: 2026-11-09
children:
  - id: 1a2b3c4d5e6f
    text: 要件定義
    duration: 3d
  - text: 設計
    duration: 2d
    after: "[[1a2b3c4d5e6f]]"
```

`after` があるので、設計は要件定義が終わった次の稼働日から始まる予定になります。

## スケジュール

ガントチャートは、`views: gantt` を付けた項目で使えます（「ビュー」参照）。次の属性を読みます。

| 属性 | 例 | 意味 |
| --- | --- | --- |
| `views` | `gantt` | ガントチャートを有効にする（「ビュー」参照） |
| `duration` | `3d` / `2w` / `10cd` / `0d` | 期間（稼働日 / 週 / 暦日）。`0d` はマイルストーン |
| `start` | `2026-11-10` | この日より前には始めない。子にも継承される |
| `end` | `2026-11-14` | `duration` の代わりに終了日を書く。`start` からこの日までのバーになる（暦日なので土日も含む）。依存がもっと遅く終わると、バーごと後ろにずれる |
| `after` | `[[要件定義]], [[API 設計]]` | 依存。すべて終わってから始まる。親の依存は子にも効く |
| `due` | `2026-11-20` | 期限。過ぎて終わると遅延として表示 |
| `completed` | `2026-11-09` | 完了した日（⌘Shift+Enter で自動で付き、再開すると消える） |
| `workdays` | `mon-fri` | 稼働する曜日（既定は `mon-fri`）。子にも継承される |
| `holidays` | `jp`, `2026-12-29..2027-01-03` | 休日。`jp` で日本の祝日を加える |

子を持つ項目は、子の期間全体にまたがります。★ はクリティカルパス（遅れるとプロジェクト全体が遅れる作業）です。ガントチャートには依存の矢印と期限の線が出て、− / + で1日の幅を変えられ（長いプロジェクトなら年と月の目盛りまで縮小）、**全体** でスケジュール全体が入る幅になります。**日付** で、項目名の右に開始日・終了日・日数（稼働日）の列を出します。チャートの上のボタンで、項目名・日付・凡例ごと SVG・PNG ファイルとして保存したり、画像としてコピーしたりできます。

ガントチャートの上でも日程を編集できます。変更は属性として書き込まれるので、アウトラインと同じものです。

- **バーをドラッグ**: 開始日を動かします（`start` が付きます。`end` で書いた項目は `end` も一緒にずれます）。依存先より前には動かせず、依存先が終わった後の位置で止まります。
- **バーの右端をドラッグ**: 終了日を動かします。`duration` を稼働日数で書き換えます（`10cd` のような暦日の項目は暦日のまま、`end` で書いた項目は `end` を書き換えます）。
- **名前・開始・終了・日数をクリック**: その場で入力できます。日付は `12/3` のように月/日でも書けます（今年として読みます）。日数を `0` にするとマイルストーンになります。日程のない項目に開始日や日数を入れれば、そこから日程が付きます。Enter で確定、Esc で取り消しです。
- **依存を作る**: バーにカーソルを当てると、右に小さな丸が出ます。そこから、後に始めたい行までドラッグすると、その行の `after` に依存が足されます。循環してしまう依存や、親子の項目の間の依存は作れません。
- **依存を消す**: 矢印をクリックして選び、Delete（または矢印に出る ×）で消します。その行の `after` から外れます。
- 名前の右の **›** で、その項目にズームします。

子の期間から決まる親の項目（まとめのバー）は、ここでは編集できません。ドラッグ中は Esc でバーを元に戻せます。

## 図

図ビューは、`views: diagram` を付けた項目で、ズームしている項目の行を図にします。たとえばシステム構成図:

```
・本番環境
  ・views: diagram
  ・ユーザー
    ・shape: actor
    ・to: [[Web]] HTTPS
  ・VPC
    ・shape: frame
    ・Private
      ・shape: frame
      ・Web
        ・to: [[API]] gRPC
      ・API
        ・to: [[DB]]
      ・DB
        ・shape: db
```

と書くと、次のように描かれます:

```
      ┌ VPC ─────────────────────────┐
      │ ┌ Private ─────────────────┐ │
☺ ──▶ │ │ Web ─gRPC─▶ API ──▶ (DB) │ │
      │ └──────────────────────────┘ │
      └──────────────────────────────┘
```

| 書き方 | 描かれ方 |
| --- | --- |
| 行 | 箱。下の行は箱の中に `• …` で並ぶ |
| `shape: frame` | 下の行を囲む枠。中の行はそれぞれ箱になる。枠線は `frame solid` / `frame none`（既定は点線） |
| `shape: container` | 中に箱を並べる箱（入れ物）。枠と同じく下の行が箱になり、見た目は普通の箱 |
| 属性の中の `[[リンク]]` | 矢印。リンクの後ろの言葉（なければ属性名、`to` を除く）がラベルになる。`after` の矢印は依存先から引かれる |
| `shape` | `box` / `actor` / `db` / `queue` / `external` |
| `color` | `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray` または `#hex` |
| `icon` | 名前の前のアイコン: `server`, `database`, `storage`, `cloud`, `globe`, `user`, `users`, `mobile`, `desktop`, `browser`, `code`, `function`, `queue`, `bolt`, `lock`, `key`, `shield`, `mail`, `bell`, `chart`, `gear`, `container`, `file`, `search`, `cpu`、または絵文字。actor では人型の代わりになる |
| `note` / `description` | 箱や枠の名前の下に出る説明文。折り返して表示し、長いと箱が横に、さらに縦に広がる。`note` のブロックでもよい |
| その他の属性 | 箱の中の小さな `key: value` の行 |
| `layout`（枠か、ズームした項目に） | 中の箱を矢印に関係なく、アウトラインの順に並べる。`row` / `横`: 横一列、`column` / `縦`: 縦一列、`grid` / `格子`: 格子状に折り返す（`grid 3` で3列。省略するとほぼ正方形になる列数）。中の矢印は線を引くだけで、並びには使わない |
| `direction`（ズームした項目に） | `LR`（左から右、既定）/ `TB`（上から下） |
| `diagram`（ズームした項目に） | `flow`: 矢印に沿って並べる（矢印か枠があるときの既定）、`tree`: マインドマップ |

線の見た目は、書いた属性の名前で決まります。`async:` は点線、`both:` は両矢印、`link:` は矢印なし、それ以外（`to:` など）は普通の矢印です。ズームした項目に `lines` 属性を置くと、名前ごとに決められます: `calls: dotted red`、`sync: both`（`solid` / `dashed` / `dotted`、`arrow` / `both` / `none`、色）。

箱の中に並んだ行への矢印は、その箱に引かれます。マインドマップ（`diagram: tree`）では枠も含めてすべての行を描きます。箱を横切る線は迂回します。図の上のボタンで SVG・PNG ファイルとして保存したり、画像としてコピーして資料に貼ったりできます。

図の上でもそのまま編集できます。書き換わるのはアウトラインの行と属性なので、図とアウトラインはいつも一致します。

- **名前**: 箱をダブルクリック（選んで Enter）で書き換えます。
- **形・色**: 箱を右クリックしたメニューで選びます（`shape` / `color` 属性になります）。同じメニューから、中や後ろに箱を追加したり（普通の箱の中に追加すると、その箱は入れ物になります）、アウトラインで開いたり、削除したりできます。
- **箱の追加**: 図の左上の **+ 箱を追加**。
- **矢印**: 箱にマウスを乗せると出る点から、つなぎたい箱までドラッグします（`to: [[箱]]` が付きます）。矢印をクリックして × か Delete で消せます。
- **移動**: 箱を別の枠へドラッグすると、その枠の中に移ります。普通の箱の真ん中に落とすと、その箱が入れ物（`shape: container`）になって中に入ります。端に落とすとその箱の前に並びます。入れ物が空になると普通の箱に戻ります。`layout` で並べた枠の中では、落とした位置で順番が入れ替わります。ドラッグ中に Esc で取りやめます。
- 選んだ箱は Delete で削除できます（⌘Z で戻せます）。

## スライド

`views: slides` を付けた項目で使えます。ズームした項目がデッキ、その下の各行が1枚のスライドです。スライドの下の行は箇条書き、ブロックは本文になります。← → でページ送り、F で全画面、N でスピーカーノートを表示します。

| 属性 | 付ける場所 | 意味 |
| --- | --- | --- |
| `subtitle` | デッキ、スライド | サブタイトル |
| `theme` | デッキ | `dark` で暗いテーマ |
| `layout` | スライド | `center` / `two-column` / `title` |
| `notes` | スライド | スピーカーノート |
| `image` | スライド | 画像（URL、または貼り付けた画像の `files/….png`） |
| `embed` | スライド | `[[項目]]` のガントチャートを埋め込む（`[[項目]] diagram` で図） |

## 検索

検索（⌘F）は、書いた条件をすべて満たす行を探します。Esc で解除します。

| 条件 | 一致するもの |
| --- | --- |
| `word` / `"two words"` | 本文・属性名・値に含む |
| `status:active` | 属性 `status` の値に `active` を含む |
| `budget.amount:1200` | 入れ子の属性 |
| `due:` | 属性 `due` を持つ |
| `is:done` | 完了した行 |
| `is:task` / `is:todo` | タスク / 未完了のタスク |
| `is:ready` / `is:blocked` | 着手できる / 依存待ち |
| `is:late` / `is:critical` / `is:milestone` | 遅延 / クリティカルパス上 / マイルストーン |
| `is:cycle` | 依存が循環している |
| `-条件` | 否定 |

`is:` は日本語でも書けます（`is:完了`、`is:タスク`、`is:未完了`、`is:着手可`、`is:待ち`、`is:遅延` など）。大文字・小文字や全角・半角の違いは区別しません。

## ビュー

表示バーで切り替えます。項目ごとに、最後に使ったビューを覚えています。

アウトライン・テキスト・YAML・JSON はどの項目でも使えます。ガント・図・スライドは、そのために書いた行でないと意味をなさないので、項目ごとに有効にします。表示バーの **+** から選ぶと、その項目に `views` 属性が付き、項目とその下の行すべてで使えるようになります。`views: gantt, slides` のように直接書いても同じです（`gantt` / `diagram` / `slides`、または `ガント` / `図` / `スライド`）。

- **アウトライン**: すべての編集ができます。
- **ガント**: スケジュールをチャートで表示します（「スケジュール」参照）。`views: gantt` で有効になります。
- **図**: 行を箱と矢印で描きます（「図」参照）。`views: diagram` で有効になります。
- **スライド**: 行をスライドとして表示します（「スライド」参照）。`views: slides` で有効になります。
- **テキスト**: 行を Markdown のリストで表示します。ほかへの貼り付け用です。リンクは項目名に、タスクはチェックリストになり、「タスクだけ」「完了」「属性」の切り替えが効きます。
- **YAML / JSON**: ズームした項目をデータとして、色付き・読み取り専用で表示します。コピーボタン付きです。リンクされている項目には `id` が付きます。

## 保存

アウトラインは入力するたびに自動で保存されます（上部のバーに状態が出ます）。別のタブやアプリの外でファイルが変わったときは、読み込み直すか自分の内容で上書きするかを選べます。

ファイルに保存しているときは、その日最初の保存の前と、一度に 10 行以上を消した保存の前の内容が、データファイルの隣の `backups/` フォルダに残ります（日ごとのものは 30 日分、行を消す前のものは時刻付きで直近 20 個）。貼り付けた画像やファイルは `files/` フォルダにあり、一度保存したものは書き換えられません。ブラウザにもデータファイルごとに控えが残り、ファイルがなくなったときは、そのファイルの控えから作り直します（控えがなければサンプルから始まります。別のデータファイルの内容が使われることはありません）。

**⋯** メニューから、読むためやほかのツールに渡すための **YAML**、元に戻せる **バックアップ（JSON）** として書き出せます（画像やファイルは含まれません）。ファイルに保存しているときは、アウトラインとそこで使っている画像・ファイルをまとめた **バックアップ（ZIP）** も書き出せ、**バックアップから読み込む** で JSON・ZIP どちらからも復元できます（ZIP の画像・ファイルは `files/` に戻ります）。

**使われていないファイルを整理** は、アウトラインにも `backups/` のどのバックアップにも残っておらず、1週間以上前に追加された画像・ファイルを削除します。削除する数と大きさを確認してから実行します。使い方のスライドとサンプル（スケジュール付きのプロジェクト、システム構成図）も、ここからいつでも追加し直せます。
